Pure Devices OpenMatlab

Version 2025-Nov-25

Download installer
  • Add new parameters Seq.InterferenceFrequencyTEcho and Seq.InterferenceFrequencyRepetitionTime in sequence_Spin_Echo to separately select an echo time or a repetition time that should suppress the effect of an interference source with that frequency.
  • When using (the non-default) parameter Seq.iLaplace1D.SpectrumWeight with get_iLaplace1D, the effect of these weighting factors on the spectrum amplitudes had not been reverted in prior versions.
  • Add new parameter PenalizeStepHeight for get_iLaplace1D and get_iLaplace2D which can be used optionally to regularize the inversion by penalizing the step height between neighboring bins in the spectrum (instead of penalizing the absolute spectrum amplitude).
  • Other changes and improvements.

Version 2025-Nov-13

Download installer
  • Fix issue in sequence_Spin_Echo when calculating the spoil factor if Seq.AQSlice(1).SpoilFactorEnd(3) (spoiler in read direction at end of echo train) is set to Inf.
  • Add new parameter Seq.AQSlice(1).RephaseLengthFactorEnd in sequence_Spin_Echo. This factor applies to the phase rephase and read rephase gradients and the spoilers at the end of echo trains.
  • Add new parameter Seq.InterferenceFrequency in sequence_Spin_Echo which can be used to set the echo time and repetition time to values that should suppress the effect of an interference source with that frequency.
  • Implement improvements to the error propagation in the function get_MeanPhaseDiffWeighted. That affects, e.g., the value of the standard uncertainty returned by the frequency search functions.
  • Try to propagate the error from the frequency tracking in imaging sequences (Seq.CorrectPhase for sequence_Flash and seuqence_Spin_Echo), and warn if the correction is uncertain (and might actually lead to more artifacts in the image reconstruction).
  • Try to discard information from measurements with Find_Frequency_Sweep that is too close to the Nyquist frequency of the respective acquisition window.
  • Many other changes and improvements.

Version 2025-Oct-24

Download installer
  • Add new script Example_Flash_3D_B1 that can be used to measure a 3-d B1 map.
  • Add new parameter Seq.Function_Find_Frequency for sequence_Spin_Echo and sequence_Flash that allows overriding the function that is used to optionally adjust the frequency at each iteration of the measurement loop.
  • Fix some compatiblity issues with MATLAB R2025a and R2025b.
    Note that not all issues in these versions of MATLAB can be worked around. Use an older version of MATLAB for best experience.
  • Add marker for the center of the object and display its distance from the center of the magnet in the plot that is displayed by the localizer scripts.
  • Implement new features for sliceomatic objects. Among other changes that includes methods to export as .avi videos or in VolView format.
  • Support exporting 3-d ZTE or SPI measurements to VolView files with Image3D2VolView.
  • Add option for get_ReadParameter to extend the readout gradient by a given number of samples (before and after the acquisition window).
  • Fix using sequence_Spin_Echo with Seq.SingletRep in combination with dual nuclear imaging.
  • Add optional argument idxModule for get_PhaseParameter, get_ReadParameter, and get_SliceParameter to select which module indices should be translated to the pulse program matrices (i.e., the fields in the AQ, Grad, and TX structures).
    This allows skipping module indices for which not all necessary fields have been set yet.
  • Fix some (floating point precision) issues if HW.RX.DataClassSingle is set to true.
  • Fix inconsistency in the values of data.fft1_data if a software decimation factor is used.
  • Initialize device with current shim values (if they are not too high).
  • Fix potential issues with the frequency correction of the earliest and latest acquisition windows in imaging sequences.
  • Make some improvements for the "dummy" mode.
  • Fix some compatibility issues of the device connection via socket server in combination with the .NET pulse program generator.
  • Minor improvements for non-Windows platforms. (Not officially supported yet.)
  • Many other changes and improvements.

Version 2024-Nov-29

Download installer
  • The direction in which the image center moves relative to the origin of the gradient system when using Seq.AQSlice(1).distance is more consistent (and in accordance with the documentation) now. IMPORTANT: This means that existing measurement scripts in which images are shifted in phase or read direction are shifted in the opposite direction compared to before this change.
  • Support triggered tReps also if the first tRep in a pulse sequence is not triggered.
  • Improve stability of fit for loaded Q-factor in Smith chart for Network Analyzer.
  • Newly created LoadMySystem.m scripts will check the serial number of the connected MRT device. That helps to avoid potential issues if one OpenMatlab installation is used with different MRT devices.
  • Add support for tracking the frequency in sequence_Flash at a different resonance than the one used for the image acquisition (for double-resonant coils).
  • Improve timing of frequency tracking acquisition windows in sequence_Flash.
  • Avoid more double precision errors when using shaped rf-pulses or when adding gradient pulses.
  • Support setting the relative distance of the AQ frequency to peaks from harmonics of DC/DC converter (HW.MMRT.fPowerSyncDist).
  • Improve compatibility of sliceomatic with newer versions of Matlab.
  • Improve behavior of axes background color when printing sheerPlot figures.
  • Add initial support to query ID of connected probe (for new devices with exchangeable probe).
  • Many other changes and improvements.
